# Neovim README

## Lua Files for Neovim Configuration 
                                                                                                       
 This repository contains a collection of useful Neovim plugins and configurations, organized into     
 separate directories for each plugin or configuration. The `edit_util` directory contains a number of 
 Lua scripts that can be used as utilities within Neovim, while the other directories contain specific 
 plugins or configurations that can be installed and configured in Neovim.

## Column Align Test (-c)

Table (-ct) 

- a | b  | c
- dd | ee | ff
- ssss | eeee | fs

Fat Forward ("ff" / -ca) 

- asdf => qwer => qwer
- a => b => c
- bb => cc => dd
- gg => hhhh => ding

Arrow Forward ("-f" / -ca) 

- asdf -> qwer -> qwer
- a -> b -> c
- bb -> cc -> dd
- gg -> hhhh -> ding

Arrow Reverse ("-r" / -ca)

- bing <- bong <- tont
- bb <- rr <- gg
- hhh <- eee <- fff

Pipe Forward ("|f" / -ca )

- asdf |> qwer |> qwer
- a  |> b  |> c
- bb |> cc |> dd

Pipe Reverse ("|r" / -ca)

- bing <| bong <| tont
- bb <| rr <| gg
- hhh <| eee  <| fff

Tilde Forward ("~f" / -ca )

- asdf ~> qwer ~> qwer
- a  ~> b  ~> c
- bb ~> cc ~> dd

Tilde Reverse ("~r" / -ca)

- bing <~ bong <~ tont
- bb <~ rr <~ gg
- hhh <~ eee  <~ fff

Equal Forward ("=f" / -ca )

- asdf >= qwer >= qwer
- a  >= b  >= c
- bb >= cc >= dd

Equal Reverse ("=r" / -ca)

- bing <= bong <= tont
- bb <= rr <= gg
- hhh <= eee  <= fff
